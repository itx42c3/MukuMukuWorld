# MukuMukuWorld

Sonolus / NextSekai 向けのブラウザ譜面エディタです。

**https://mukumuku.netlify.app**

インストール不要で、上記URLにアクセスするだけですぐ使えます。iPad（横向き固定・Apple Pencil + 外部キーボード + 指タッチ対応）での利用を主眼に設計していますが、PC のブラウザからも利用できます。

## 主な機能

- ノーツ種: Tap / Critical / Flick / Critical Flick / Trace / Critical Trace / Friction / Critical Friction / Damage / Slide（中継点つき）
- USC（Sonolus Universal Chart）形式での入出力
- 音声ファイル読み込みと Web Audio API によるリアルタイム再生・シーク・BGM 同期
- 波形タイムライン表示
- Undo / Redo（最大100ステップ）
- 自動保存（クラッシュ・再読み込み対策、端末内に保存）
- PWA 対応（オフライン起動、ホーム画面追加、横向き固定）
- 外部キーボードショートカット、指タッチ / Apple Pencil 両対応の編集操作

## はじめかた

### 1. サイトを開く

Safari（iPad）または任意のブラウザで以下にアクセスします。

```
https://mukumuku.netlify.app
```

### 2. ホーム画面に追加する（iPad推奨）

アプリのように使うには、ホーム画面への追加をおすすめします。オフラインでも起動でき、フルスクリーンで動作します。

1. Safari で上記URLを開く
2. 共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択
4. 追加されたアイコンから起動
5. 画面を横向きにしてお使いください（縦向きでは操作警告が表示されます）

### 3. 譜面を作りはじめる

- 新規に作る場合はそのまま譜面エリアで編集を開始できます
- 既存の USC ファイルがある場合は、ファイルメニューから読み込めます
- 音声ファイル（mp3/wav等）を読み込むと、BGMに合わせて編集できます

## 操作方法

### ツール選択（左パレット）

パレットのボタンをタップしてツールを切り替えます。外部キーボードでは数字キー `1`〜`9` でも切替可能です。

### ノーツ配置

配置系ツールを選んだ状態で譜面エリアをタップ（または Pencil でタップ）すると、その位置にノーツが置かれます。
スナップ位置は下部トランスポートの「スナップ」設定（1/4 〜 1/48）に従います。

### スライド作成

「スライド作成」または「Cスライド作成」を選択し、始点から終点までポインタをドラッグします。
経由した点が自動的に中継点（anchor）になります。

### 選択・移動

「選択 / 移動」ツールでノーツをタップすると選択され、右パネルで詳細（レーン・幅・Tick・フリック方向）を編集できます。
指でのドラッグは画面スクロール、Pencil / マウスでのドラッグはノーツ移動に割り当てています。

### 再生

下部トランスポートの「音声読込」でBGMファイル（mp3/wav等）を読み込み、再生ボタンまたは外部キーボードの
スペースキーで再生・一時停止します。再生中は自動でプレイヘッドが譜面上を移動します。

### 保存・書き出し

ファイルメニューから USC 形式で書き出し（エクスポート）できます。編集内容は端末内にも自動保存されるため、
アプリを閉じても続きから再開できます。

### キーボードショートカット（外部キーボード利用時）

| キー | 動作 |
|---|---|
| Cmd/Ctrl + Z | 元に戻す |
| Shift + Cmd/Ctrl + Z | やり直し |
| Delete / Backspace | 選択削除 |
| Esc | 選択解除・選択ツールに戻る |
| Space | 再生 / 一時停止 |
| +/- | 縦ズーム |
| 1〜9 | ツール切替 |

## データ形式についての注意

- **USC**: コミュニティで広く使われている Sonolus Universal Chart 仕様に準拠した実装です。
- 以前対応していた MMWS（MikuMikuWorld4CC プロジェクト形式）や SUS（テキスト譜面形式）は、現在は非対応です。USC 形式のみサポートしています。

## 既知の制限

- 判定音（ヒットサウンド）のプレイバックは未実装です
- レーン数・判定ライン位置などはProSeka標準（12レーン）に固定しています
- マルチタッチでの複数ノーツ同時配置（コード配置）は未対応です

## データが消えてしまったら

自動保存は端末（ブラウザ）内に保存される仕組みのため、ブラウザのキャッシュ・データを消去すると編集中の譜面も失われます。
大事な譜面は作業のこまめな区切りで USC ファイルとして書き出し、端末やクラウドストレージに保存しておくことをおすすめします。
